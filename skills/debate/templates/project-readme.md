## Folder layout

```
<project folder name>/
├── sources/     the files the user supplied, unchanged (<one line on what they are>)
├── agent/       everything the agents made: the debate record
└── outputs/     the Reports
```

Nothing in `sources/` was written by an agent. Everything in `agent/` and `outputs/` was.

### `agent/`

| File | What it is |
|---|---|
| `motion.md`<, `motion-<lang>.md`> | the Motion, scope, <N> Dimensions<in groups A–…>, Source Tier examples, the user's sources mapped to their text extracts |
| `state.md` | Stage status<, Advocate groups>, Evidence Requests, log |
| `1-opening-<side>-<group>.md` | Stage 1: each Advocate's opening case |
| `2-rebuttal-<side>-<group>.md` | Stage 2: a response to every opposing Claim |
| `3-audit-batch-<N>.md`, `3-audit.md` | Stages 3 and 4a: the Auditors' checks, and the summary with counts per Side |
| `4-rejoinder-<side>-<group>.md` | Stage 4: answers to the Rebuttals <(skipped in quick mode)> |
| `notes-<side>-<group>.md` | each Advocate's working notes between Stages |
| `ledger.md` | index of all Evidence, generated by `ledger.py` |
| `figures.json`<, `figures-<lang>.json`> | data and captions of the Judge's charts |
| `evidence/E-*.md` | one file per Evidence item: source, verbatim quote, translation, Audit verdict |
| `evidence/files/` | the text the agents quoted from: `user-*.txt` are extracts of the files in `sources/`, the rest were fetched by the agents (`web/` holds fetched pages) |

<Groups: **A** <short theme>, **B** <short theme>, …>

Evidence IDs show who added them: `E-PRIMARY-001` is the Primary Text, `E-PRO-…` and `E-CON-…` were added by the Pro and Con Advocates<, with the group letter after the Side: `E-PRO-B-012` is the Pro Advocate of group B>, `E-USER-…` came from the user.

## Rebuilding the Reports

After editing `outputs/report*.md` or `agent/figures*.json`, run from this folder:

```
python3 <skill dir>/scripts/ledger.py .
uv run --script <skill dir>/scripts/report_html.py .
<uv run --script <skill dir>/scripts/report_html.py . --lang <lang>>
```

Each prints any problems it finds; a clean run prints only the "written" line.<The Reports in each language mirror each other, so make every change in all of them.>
