# The Report never recommends a vote, and the Judge never sees the user's leanings

The Report maps Open Questions and Value Questions and gives a Cheat Sheet for each Side, but it never declares a winner or recommends a vote. Once the facts are sorted, most Motions turn on values, so a verdict would quietly substitute the Judge's values for the user's. For the same reason, Framing collects only the scope (what, where, when, arguments heard) and never the user's leanings, and the Judge is a fresh subagent that sees only the debate record, so no participant is steered toward the answer the user hopes for.

## Consequences

Verdict-free does not mean false balance: when one Side's case rests on weaker Source Tiers or mostly Value Claims, the Report says so plainly.

The Confrontation is bound by the same rule. It ends without a summary or a verdict, adds nothing beyond the record, and says on its face that it is an edited rendering of the written cases. Both Sides write each Stage in parallel, so the Confrontation's order is a fixed convention: Pro first at every Stage, Con speaking last in each Dimension. The last word is not the winning one.
