# The Report never recommends a vote, and the Judge never sees the user's leanings

The Report maps Factual Cruxes and Value Cruxes and gives a Cheat Sheet for each Side, but it never declares a winner or recommends a vote. Once the facts are sorted, most Motions turn on values, so a verdict would quietly substitute the Judge's values for the user's. For the same reason, Framing collects only the scope (what, where, when, arguments heard) and never the user's leanings, and the Judge is a fresh subagent that sees only the debate record, so no participant is steered toward the answer the user hopes for.

## Consequences

Verdict-free does not mean false balance: when one Side's case rests on weaker Source Tiers or mostly Value Claims, the Report says so plainly.
